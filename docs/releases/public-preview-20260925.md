# Public preview — 2026-09-25

Project: **RP-SceneReal2Sim**

Repository: **Roboparty/RP-SceneReal2Sim**

This release presents the previously verified implementation as a community research-engineering workflow for robotics and embodied-AI developers.

## Changes

- Public project identity and bilingual READMEs.
- Furniture-dimension and exact-model enhancement guide, with implementation and evidence status explicitly separated.
- MIT licence for project source/text/metadata; separate publication notice for example media and dependency references.
- Existing walkthrough, comparison video, structure regression records, physical demonstrations, and replay instructions retained.

## Evidence scope

The generation, rendering, and physics algorithms are unchanged from snapshot `ac720a8`. This release does not add an automatic SKU search service, a universal CAD importer, a new reconstruction backend, or a new physical experiment. The example remains model version 4 / candidate 019.

The real-photo example uses common size priors and all-fallback B. It demonstrates structural correction and the documented checks; it does not quantify catalogue-dimension or exact-asset enhancement.

Historical six mesh regression scenarios, eight contract checks, 18-stage A/B records, and frozen-case replay evidence are retained. Publication checks are recorded separately in `PUBLICATION_VALIDATION.json` at the repository root.

The prior private snapshot remains in Git history. References to private delivery in historical task records describe their original distribution scope; current publication and media terms are stated in [PROVENANCE.md](../../PROVENANCE.md) and [MEDIA_NOTICE.md](../../MEDIA_NOTICE.md).
