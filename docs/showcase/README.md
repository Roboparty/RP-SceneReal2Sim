# 三个房间的重建

从卧室、货架房和杂物房三张照片分别建立可编辑场景。结合确认的床长和两款候选家具规格校正尺寸与摆放，拆分家具部件，并为选定物体设置交互。

[播放 45 秒完整版](https://github.com/Roboparty/RP-SceneReal2Sim/raw/refs/heads/main/docs/showcase/media/overview.mp4)

![实拍与重建](media/comparison.jpg)

视频保留三场景 V5 原交付：照片对照、实际相机移动、多视角、黑柜铰链、衣物以及 ArtVIP 柜体对照。黑柜使用 Blender Bullet 铰链/电机，两件衣物使用 Cloth，其余三件静态；两款家具与 ArtVIP 的开合是运动学回放，没有执行 ArtVIP 原生 PhysX。部分多视角采用剖视，房间模型保留围护结构。

## 资产与测量

包含 18 个装配实例及 3 个床品组件，共 21 个静态资产文件；床整体包含这三个床品组件。独立静态文件不携带主场景的动态求解器。仓库发布清单、预览和评估脚本，未分发大型 Blender 文件与缓存。

2026-09-25 在 V5 模型上重新执行逐资产尺寸、网格和表面距离测量。完整数值、参照定义、发现的问题与复查方法见 **[定量评估](ACCURACY.md)**。

## 与复跑案例的关系

| 内容 | 三场景 V5（本页） | 仓库复跑案例 |
|---|---|---|
| 输入 | 三个房间的照片，分别重建 | 一张杂物房照片 |
| 尺度依据 | 2m 床长、候选柜体规格，其余估计 | 层高与常见家具尺寸先验 |
| 运动 | Blender Bullet / Cloth；家具柜体运动学回放 | MuJoCo 铰链、薄片布料、体积柔体 |
| 仓库入口 | 预览、资产清单、独立测量脚本 | [复跑配方](../example/REPLAY.md)与[验证结果](../example/RESULTS.md) |

本页视频不是当前复跑命令的输出。展示案例沿用了较早的场景建模流程，其评估结果也不替代复跑案例的验收。
